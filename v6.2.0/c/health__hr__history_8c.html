Detailed Description

The health store's heart rate graph: the last hour of heart rate, a reading a minute, saved to flash so a relaunch shows it straight away. A face turns it on with HEALTH_HR_HISTORY, and one that never names it carries none of this.

◆ hr_history_heart_rate()

void hr_history_heart_rate ( int hr,
bool from_event )
static

Slides the window to now and puts a new reading in its last slot.

The chart reads from this window rather than the minute history: the watch only logs a per-minute heart_rate_bpm now and then in the background, so the minute history is mostly empty, while peeking the live value on each event fills the window with real readings.

Parameters
hrThe reading in beats per minute, or -1 for none.
from_eventUnused, since a peek is as good as an event for the graph.

◆ persist_save()

void persist_save ( void )
static

Stash the heart rate graph so a relaunch can restore it.

Only a live face writes, so seed mode never touches storage. A burst can land a reading a second and a flash write blocks, so the saves are held to one a minute, which is all the graph gains anyway.

One a minute is the rate to keep, not one to trim. The save runs from whichever comes first in a new minute, the face's cadence turn or a health event that refreshes the heart rate. Either way the CPU is already awake for it, so no extra wake is spent. The face is closed whenever the wearer opens a watchapp, even for a moment, and a graph saved less often comes back missing its last minutes every time.

◆ read_hr_history()

void read_hr_history ( time_t now_min)
static

Fill the empty minutes of the heart rate window from the watch's own minute log.

Used at launch, on an empty window or on a restored one slid forward over the time the face was away, so the minutes spent in a watchapp show what the watch logged. A minute that already holds a reading keeps it, since the live readings can be more frequent than the log. Each reading lands in the slot for its own minute.

Parameters
now_minThe minute the window's last slot holds, the same one the live readings write.
