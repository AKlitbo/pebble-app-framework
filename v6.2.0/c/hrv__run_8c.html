uint32_t root_floor ( uint32_t value)
static

The square root of a whole number, rounded down.

The watch has no hardware floating point, so this walks the bits instead of calling sqrt.

Parameters
valueThe number to take the root of.
Returns
The largest whole number whose square is no more than value.
