Detailed Description

The health store's hourly steps: today's steps by the hour for a bar chart. A face turns it on with HEALTH_STEP_HISTORY, and one that never names it carries none of this.

Function Documentation

◆ read_step_hourly()

void read_step_hourly ( void )
static

Fill the per-hour step buckets from midnight up to the current hour.

step_hours records how many buckets are real so the chart can tell a quiet hour from one that has not happened yet.

An hour is read as it rolls over and once more the minute after, then never again. The hour in progress is today's total less the settled ones, which is free. Each real read blocks on a scan of the watch's whole minute log, so they stay off the minute path.

void step_history_steps ( int steps)

Brings the buckets up to date after the store read the day's step count.

The store only reads the count once a minute at most, so this runs at that pace too. The first read of all is owed to the launch timer, which runs once the face is on screen.
