Detailed Description

What a dev build takes from the unit's paf.dev.config.json beyond the walk and the clock: the date, the settings it applies at launch, the readings it seeds in place of the fixture, and the steps of a walk the file lays out as a list.

paf build –dev writes the face's share of the file into a header the build puts beside the settings page's, and dev_config.c is the only file that includes it. The theme walk in dev_walk.c asks here before it seeds each store, and runs a listed walk through here, so a face reaches all of it through the hooks in dev_hooks.h. With dev mode off every call here is an empty inline, and dev_config.c compiles to nothing.

A face whose walk lists panels defines dev_show_panel, and one whose walk lists layouts defines dev_show_layout. A dev build whose walk needs one the face lacks stops at the link, naming it.
