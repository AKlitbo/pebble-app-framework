Detailed Description

Reads the Goal Met Vibration pick, and turns a comma list of milliseconds into a rhythm the watch can buzz.

The tune comes from the settings page, not the watch. The pick is a short string: empty for None, one letter for a plain pulse (S, L, or D), C for the wearer's own pattern, or a comma list of milliseconds for a fanfare. So the watch carries no tune tables of its own.
