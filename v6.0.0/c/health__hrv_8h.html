Detailed Description

The heart rate variability half of the health store. It asks the watch for beat gaps now and then, holds the sensor on while a burst is measured, and keeps the latest reading.

Only the health store calls these. A face turns HRV on with HEALTH_HRV in its appinfo's defines and the HRV fields of HealthConfig, and reads it back through the health store.
