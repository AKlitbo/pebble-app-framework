Detailed Description

The struct the framework keeps the weather and calendar source choice in, for a face built with a plugin define, and the checks that decide which of the two it keeps.

The watch never reads the choice. It stores what the settings page saves and sends it back when the phone asks for the watch's settings, so a wearer who picked the Pebble app's plugin still has it after the Pebble app is reinstalled. settings.c builds its schema from PLUGIN_SOURCE_FIELDS and walks it after the face's own, on SETTINGS_PLUGIN_SOURCE_KEY, so the face writes no field of its own for it. A save skips the write while flash already holds the choices.

A kind keeps its choice when its define is on and the face declares its select key. The build refuses the select key beside a plugin only providers list, so a plugin only kind keeps nothing. The build also writes each kept kind's default as PLUGIN_SOURCE_WEATHER_DEFAULT or PLUGIN_SOURCE_CALENDAR_DEFAULT, from the face's providers list, so the watch's default is always the settings page's. The build stops when the face's own picker does not offer it, or when the page opens on another source.
