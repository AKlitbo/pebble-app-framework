Detailed Description

The health store's heart rate day: today's heart rate by the hour, filled from the watch's minute log at launch and from each reading after. A face turns it on with HEALTH_HR_DAY, and one that never names it carries none of this.

void hr_day_heart_rate ( int hr,
bool from_event )
static

Adds a new reading to its hour, at most one a minute.

Only a heart rate event brings a new reading. A peek on the cadence can hand back the same one for up to fifteen minutes, which would count it many times. While HRV holds the sensor on, a reading lands about once a second, and keeping one a minute weighs those minutes the same as the rest of the day, where the watch logs one now and then.

Parameters
hrThe reading in beats per minute, or -1 for none.
from_eventTrue when a heart rate event brought it.

◆ read_hr_day()

bool read_hr_day ( void )
static

Fills today's hours from the watch's minute log, from midnight up to the minute the store started.

The log holds a reading for each minute the sensor took one, the same as it holds the steps, so the hours before launch read the same as they would have live. It is a blocking scan of the log, so it runs once, after the face has painted.

Returns
False when there was no room for the records, so the read is still owed.
