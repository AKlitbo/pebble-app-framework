Detailed Description

Turns the beat gaps the watch reports into heart rate variability, as RMSSD in ms.

The watch hands over one gap between two heartbeats at a time. One gap is just the heart rate said another way, so the number worth showing is how much each gap differs from the one before it, taken over a run of clean beats. That is RMSSD, the square root of the mean of the squared differences. Plain C with no SDK, so its specs run on a PC.

Apps never see the sensor's own quality grade, so the rules for which beats count are here. A gap outside a heart rate of 30 to 200 is dropped, and so is one that jumps too far from the one before, which is what a missed or doubled beat looks like. A dropped gap also breaks the chain, so the next difference is only taken between the two good gaps after it, which really are neighbours.
