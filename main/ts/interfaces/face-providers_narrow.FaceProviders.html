    • defaults(defaults: Record<string, unknown>, narrowed: ClayConfigItem[]): void

    page

    • page(config: ClayConfigItem[]): ClayConfigItem[]

      The second pass. It drops a provider picker left with fewer than two options, with the lead line above it, and takes off the rows the first pass left to place a plugin only kind's notes. A section left with nothing but headings goes with them.

      Parameters

      • config: ClayConfigItem[]

        The settings page so far, the hook's own copy. It is changed in place.

    settle

    • settle(saved: Record<string, unknown>, pages: SettlePages): boolean

      Brings the saved settings in line with the narrowed page. It rewrites a saved provider the page cannot offer to the default, deletes the saved value of every row the first pass took off, and empties the stock cache when the stock provider the face really uses moves.

      Parameters

      • saved: Record<string, unknown>

        The saved settings, by name. Changed in place.

      • pages: SettlePages

        The face's own page and the narrowed one, with their defaults.

      Returns boolean

      True when it changed the settings, so the caller knows to save them.
