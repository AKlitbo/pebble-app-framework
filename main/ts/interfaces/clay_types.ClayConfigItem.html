    Interface ClayConfigItem

    One Clay config item (a section, heading, select, toggle, input, custom component, etc.). The fields both the config builder and the runtime touch are declared. Custom-component props ride along as optional. No index signature, so a face's own typed config array stays assignable to this.

    Optionalcapabilities

    capabilities?: string[]

    Clay's own per-item filter, resolved against the watch the page was opened from. Names come from Clay's capability map (PLATFORM_GABBRO, BW, HEALTH and so on) and take a NOT_ prefix to invert, so ['NOT_PLATFORM_GABBRO'] drops the item on a round watch and keeps it everywhere else. An item with none declared is always shown.

    OptionalhideWhenEmpty

    hideWhenEmpty?: boolean

    section only: hides the whole card while every row in it is hidden, and shows it again once any row shows. Clay draws a section as a card it cannot hide, so a section whose rows all hide would leave an empty card. dependentVisibility acts on it, and only a section carrying it is hidden.     Optionalpreviews

    previews?:
        | Record<string, ThemePreviewPictures>
        | Record<string, Record<string, ThemePreviewPictures>>

    themePreview only: the pictures for each option, keyed by the option's value as a string, from the face's theme-previews.g.js. A value is a list of data URLs, drawn side by side, so a theme can carry one picture or a few (such as a day and a night shot). A value can instead be a map keyed by platform, so a round and a rectangular watch each show their own shots. With previewsByKey set, it nests one level deeper, keyed first by the sibling control's value.

    OptionalpreviewsByKey

    previewsByKey?: string

    themePreview only: the messageKey of another control on the page whose value picks which set of previews to draw. The previews map then nests, keyed first by that control's value and then by the option's value, so the shots under the picker follow a second choice such as the scene. The named control is read once the page is built, and the preview redraws whenever it changes.

    OptionalvisibleWhen

    visibleWhen?: VisibilityCondition | VisibilityCondition[]

    Shows this item only while another control holds one of the given values, so a row that does nothing under the current choice is hidden rather than left on the page. One condition, or a list of them that all have to hold. key is a control's messageKey and in the values that reveal this item (a toggle's are true/false), or notIn the values that hide it. The framework wires the showing and hiding when a page has any, ahead of the face's own customClay.
