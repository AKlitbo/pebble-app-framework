◆ pct_of_seconds()

int pct_of_seconds ( int elapsed,
int total )
static

Seconds gone over seconds in the period, as a whole percent rounded down.

Every period is a whole number of hours, so a hundredth of one is a whole number of seconds, 36 an hour. Dividing by that hundredth gives the same answer as times 100 over the total, with no product that could run past a 32 bit int on a year of seconds. It also keeps 64 bit division, about 750 bytes of library code, off the watch.

Parameters
elapsedSeconds gone so far.
totalSeconds in the whole period, a whole number of hours.
Returns
Whole percent from 0 to 99, or 0 when either count is not positive.
