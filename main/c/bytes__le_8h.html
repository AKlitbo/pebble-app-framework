Detailed Description

Little-endian byte readers shared by the wire-decoding stores.

Each byte is read on its own and shifted into place rather than casting the pointer to a wider type, so the value comes out the same whatever the compiler believes about alignment or byte order. The casts are what carry the sign: the phone packs a temperature and a percent as signed values, and reading them unsigned turns a small negative into a large positive.
