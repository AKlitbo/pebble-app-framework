Detailed Description

One weather message as the transport read it, before anything is kept.

A group whose bit is clear left nothing in the message. Inside a group that did arrive, a number the phone left out reads INT_MIN and a string reads NULL, which is the one way this message marks a missing value. The strings and strips point into the message itself, so this only lives as long as the inbox callback that built it.
