 Shared dev harness for screenshots. It seeds the clock, weather, health, system, and location stores with a fixed fixture, and the stock and calendar stores empty, using the store seed mechanism so no live source overwrites it, and drives an accelerometer-tap theme "walk". Each tap steps to the next theme and the next fixed set of readings, on the same fixed clock.

Detailed Description

Fixed fixtures and a theme walk for repeatable screenshots.

It comes with the dev plugin, in src/plugins/dev/c/dev, apart from the runtime. The frame faces share it. It fills the stores with fixed fixtures and steps through the themes on a tap, so a face's screenshots come out the same every time. The weather and location stores are filled only for a face that declares their message keys, and left empty otherwise.
