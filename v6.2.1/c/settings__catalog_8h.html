Detailed Description

The shared catalog of known settings. A KNOWN_* macro per setting bakes in its neutral wire key, encoding, bounds, default, and side effects.

A face subscribes to a known setting by placing its KNOWN_* entry in the face's field table at the offset of the matching struct member, and by declaring the setting's MESSAGE_KEY in the face's package.json. Face-only settings are declared inline in the table instead, with an id of SETTING_COUNT or greater.

A choice the face's own settings page lists, the theme and the header font, takes its count from settings_page.h, which paf build writes into the sandbox from the page, and the face passes the size of its own table so the build stops when the two disagree. A choice the framework lists takes the framework's own count from setting_values.h, since the watch can only draw the values its own enum names.

Every entry takes its default from the same header, so a fresh watch starts on the value the settings page opens with. A setting the page does not show keeps the framework's own default.
