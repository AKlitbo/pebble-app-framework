Detailed Description

The condition token the phone sends, as a number a face can index its own art by.

The phone sends the sky as a short token, such as "RAIN", with "_NIGHT" on the end after dark. A face that draws its own art for each condition keeps a table indexed by WxCond and reads the token through wx_cond_parse. The numbers and tokens come from the same list the phone sends from, so the two cannot drift.

The face builds the table from WX_COND_EACH rather than writing its rows out. Each condition's row then names a resource after the condition, so a condition added to the list stops the face's build on a resource it has not got, wherever in the list it lands.

#define SKY_ART(name) [WX_COND_##name] = RESOURCE_ID_SKY_##name,
static const uint32_t s_art[WX_COND_COUNT] = {WX_COND_EACH(SKY_ART)};
bool night;
WxCond cond = wx_cond_parse(weather_store_cond(), &night);
uint32_t art = cond < WX_COND_COUNT ? s_art[cond] : RESOURCE_ID_SKY_NA;
