◆ tuple_int_or()

int32_t tuple_int_or ( const Tuple * tuple,
int32_t fallback )

Reads an int tuple, whatever width the phone sent it at.

A sender may pick TUPLE_INT or TUPLE_UINT for an integer, so both are accepted and the choice only decides what the top bit means.

Parameters
tupleThe tuple, or NULL when the key was absent.
fallbackReturned when the tuple is absent, is not an int, or carries a width no sender may use.
Returns
The value, or fallback.
