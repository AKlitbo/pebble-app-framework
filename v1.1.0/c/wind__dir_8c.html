int sin_milli ( int degrees)
static

Sine in thousandths, from a table every 15 degrees with the gaps interpolated.

The watch has a trig lookup but this file is pure core and cannot reach it, and pulling float maths in for one component would cost more than the table does. Straight lines between fifteen-degree stops land within a percent of a real sine, which is finer than a caller working in whole pixels or whole percent can use.
