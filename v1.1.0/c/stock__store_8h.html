Detailed Description

Active stock store. It owns the appmessage stock channel and its place on the shared cadence, so a face just hands it the rules (enabled / live / poll interval), optionally seeds it, then reads the slots and subscribes for repaints. The phone data flows straight in and nobody wires it.
