Detailed Description

An optional part of the store, such as the heart rate graph.

A face turns a part on by naming it in its HealthConfig, as HEALTH_HR_HISTORY, HEALTH_STEP_HISTORY, or HEALTH_HR_DAY. The store only calls a part through the pointer the face hands it, so a face that never names one leaves nothing pointing at its code or its data, and the linker drops the lot. A setting the store checked while running could not do that, since the linker cannot see which way it goes. The store skips any hook a part leaves NULL.
