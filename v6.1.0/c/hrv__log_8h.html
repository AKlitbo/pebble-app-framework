Detailed Description

The heart rate variability readings kept for a face's panels: the last few with what the wearer was doing, today by the hour, last night's average, and the latest of each kind.

The health store files every finished reading here and saves the lot to flash, so a face opened again after an app still has its history. Plain C with no SDK, so its specs run on a PC. The caller passes the time already broken into a day and a minute, so a clock change or a time zone is decided once, where the clock is read.
