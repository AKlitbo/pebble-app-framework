const char * band_lookup ( const char *const names[UV_BAND_COUNT],
UvBand band )
static

Looks a band up in one of the name tables.

A band is an enum, so a caller can still hand in any number. Anything outside the table gets the empty name rather than a read past its end. The compare is unsigned, so a negative value wraps to a big one and is turned away by the same check. A band < 0 test on an enum the compiler made unsigned would fail the watch build under -Werror.

Parameters
namesThe table, one name per band.
bandThe band.
