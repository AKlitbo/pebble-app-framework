Detailed Description

Font registry implementation. A flat id-indexed table of loaded handles, with the decisions about owning and freeing them in core's font_slots.c.

◆ s_resources

uint32_t s_resources[FONT_SLOTS_MAX]
static

The resource each slot's font was loaded from, read only while its state says it was.

Only fonts_load and fonts_swap reach this, so a face that calls neither leaves it out of its build.

◆ s_states

uint8_t s_states[FONT_SLOTS_MAX]
static

A FontSlotState for each slot: whether the app loaded the handle and so has to free it, and whether the slot records the resource it came from.

A system font is parked with fonts_register_system and stays unowned, because unloading one the firmware owns faults.
