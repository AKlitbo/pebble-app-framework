Detailed Description

Pure calendar math you can test off the watch. Week numbers, day counts, and month shapes worked out from plain numbers, so it needs no Pebble services and no struct tm.

The inputs are the same fields a struct tm carries, handed in one at a time so this stays pure core code. Year is the full year (2026). Month is 0 January to 11 December. Weekday is 0 Sunday to 6 Saturday. Day of the year (yday) counts January 1st as 0, like tm_yday.
